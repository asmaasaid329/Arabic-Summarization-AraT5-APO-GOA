# Arabic Abstractive Text Summarization Using AraT5

## Overview

This repository contains the implementation, experimental configurations, evaluation resources, and supplementary materials for a research study on Arabic abstractive text summarization using the AraT5-base-1024 model.

The study investigates and compares four approaches:

1. Baseline AraT5
2. Random Search
3. Artificial Protozoa Optimization Algorithm (APO)
4. Goat Optimization Algorithm (GOA)

## Research Objective

The objective of this study is to investigate the effectiveness of different hyperparameter optimization strategies in improving Arabic abstractive text summarization performance.

## Model

- Model: AraT5-base-1024

## Experimental Approaches

- Baseline model
- Random Search
- Artificial Protozoa Optimization Algorithm (APO)
- Goat Optimization Algorithm (GOA)

## Repository Contents

This repository is organized into the following main components:

- **Source Code:** Implementation of the baseline model and the optimization methods.
- **Dataset Information:** Links and details of the datasets used in the experiments.
- **Human Evaluation Materials:** Original articles and generated summaries evaluated by human raters.
- **Evaluation Scripts:** Scripts used to calculate the automatic evaluation metrics.
- **Experimental Results:** Results obtained from the different experimental approaches.

## Reproducibility

The repository is intended to provide the code and supplementary materials needed to support the reproducibility and verification of the reported experiments.

## Code and Data Availability

The source code, dataset references, experimental materials, and evaluation resources are provided in this repository for research verification and reproducibility purposes.
